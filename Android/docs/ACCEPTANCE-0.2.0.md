# Android 0.2.0 验收记录

发布日期：2026 年 11 月 12 日。主体实现提交：`4c5f870`。版本代码为 3，发布标签为 `android/v0.2.0`。

- 17 项逻辑检查通过。
- 12 项 Android 15 设备检查通过，涵盖原有索引、整理、云端读取与缓存，以及新增的双指照片流分组、查看器缩放、横屏全屏、覆盖工具栏收放、检查点关闭重开与后台索引进度。
- 后台索引检查使用隔离 WebDAV 服务，阻塞子目录时确认前台显示真实已发现数量；停止 Activity 后继续完成目录扫描，再返回确认索引已提交。检查点单独关闭并重开数据库，确认从未完成目录继续，改变源配置会作废旧检查点。
- 另定向检查视频的真实画面像素、暂停和继续播放，通过；截图包含正在播放的合成测试视频。
- 实际经过 R8 优化的正式签名 APK 独立验收通过：冷启动、照片真实像素、查看器放大、照片卷、深浅主题与设置。
- Go 引擎检查、发布 Lint 与 APK 检查通过。Lint 无错误，仍有依赖更新、KTX 写法等建议及保留品牌配色产生的单色图标提示。
- 核对正式 APK 中的后台 Worker 名称保持稳定，避免后续升级找不到已保存的任务。
- 与 0.1.1 签名一致，版本代码递增，可覆盖安装；最低 Android 11 / API 30，arm64，目标 API 35。原生组件的 16 KB 对齐检查通过，不等同于在 16 KB 系统真机测试。

照片流、加载中进度、横屏无工具栏／有工具栏及视频画面均已目视检查。截图和 XML 检查记录保存在本机 `.build/android-mobile-qa/final/`。一次模拟器验收在测试开始前出现进程启动超时；重新初始化专用测试模拟器后，完整 12 项检查通过。

本次未连接真实手机，也未使用个人照片、Mac 资源库或真实云盘账号。百度、夸克授权和各厂商后台省电策略仍未完成真机实测。后台执行遵从系统调度，系统强制停止后须重新打开应用才能恢复。
