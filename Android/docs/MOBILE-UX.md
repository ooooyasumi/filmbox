# Android 0.4.0 浏览与索引

照片流使用全部可用宽度，保持原比例。双指展开会增大照片，收拢会缩小照片；九个停留档位的目标行高为 12、20、32、50、80、115、150、230、360 dp。手势中按连续数值生成单层排布，每张照片只绘制一次，不叠加两套半透明布局；双指中心命中的照片及其内部相对位置作为锚点，松手后弹性吸附。最密集总览轻点可展开附近照片。当前日期始终以悬浮气泡显示，遇到下一分组时自然接替；随密度显示详细日期、周、月或年，分组边界有日期气泡和细分界。数量和下载状态仍位于标题下方，多选操作条只在选择期间出现。

日期分组与身份映射在后台准备，比例更新复用已有分组。手势只重排视口及上下 84 dp 左右的行，不再预计算全图库的九套布局。未知比例被确认后批量合并，在保持浏览锚点的同时以 260 ms 过渡；滚动期间延后比例重排。小资源库在手势结束后平滑靠齐边缘，避免内容悬在大块空白中。单张图片以 180 ms 淡入，不重置已加载图片；预览质量升级时保留旧画面直到新预览就绪。缩略图传输失败继续遵循统一恢复规则。

预览队列按可见照片相对视口左上角的距离排序，先覆盖全部可见项目，再在上方、下方各预取最多 12 项。不再截断云端可见项目数；最多四个实际读取／解码任务，完成后继续队列，划走会取消旧范围任务。连续滚动时以 70 ms 合并计划，避免等待手势完全停止才继续加载。中等以上尺寸的云端预览只有实际请求持续超过 160 ms 时显示小转圈；微小总览格子与本地读取不显示转圈，图片仍逐张淡入。

独立预览内存预算为堆上限的 1/20，限制在 8–24 MiB；按显示尺寸解码，预算紧张时降低预览分辨率并优先保留可见照片。此预算是解码位图预算，不代表整个应用的内存占用。照片流不重复使用 Coil 的内存位图缓存，磁盘缓存仍保留；本地小尺寸 MediaStore 图片优先复用系统缩略图。已有高清预览优先，照片流只请求缩略图，不触发全部原图下载；离开浏览界面取消预览任务。

查看器是应用内的全屏页面，图片不因工具栏收放而重新排版。横屏默认隐藏工具栏和系统栏；点按唤出，双指或双击缩放，放大后可拖动，原始倍率下左右切换，不再提供图片缩放条。旋转设备后重新适应视口，返回时保留照片流的位置。顶部操作栏避让系统状态栏与屏幕开孔；临时通知和下载提示放在底部、操作栏上方。视频使用相同风格的播放、进度与静音控件，保留按需流式加载、缓冲指示和云端模糊预览。

图片下载指示由原文件实际传输状态驱动，仅云端缓存未命中并正在传输时显示。传输结束即移除，不等待高清静帧生成；本地解码、缓存读取和快速切换不会显示“正在下载”。视频缓冲指示仅用于远端流，缓存和本地播放不显示云端下载提示。

设置为独立页面，根页面只保留分组入口：外观、浏览、云盘、存储、帮助和关于。操作说明在帮助页；隐私和许可从关于进入，不在设置底部重复显示。相邻资源库选中背景之间保留间距。

按钮、胶囊选项、输入框、滑块、开关、面板与加载指示使用共同配色、圆角及按压反馈；文件夹选择、系统权限和系统分享继续使用 Android 提供的交互。

云盘索引由 WorkManager 持久调度，同一资源库只保留一个活动任务，最多同时处理两个资源库。每完成一个文件夹，在独立 SQLite 暂存库中一并提交已发现文件、子目录和完成标记。系统中断后重试从未完成的文件夹继续，当前未完成目录可能重新请求一次。完整扫描后才更新正式索引，避免中断导致旧文件错误消失。暂停期间若源目录被修改，后续刷新会再次核对；超过七天的未完成检查点重新建立。

索引只读取目录元数据，不预下载全部原图。云端首次总数尚未知，因此进度条表示任务进行中，旁边显示真实的已发现项目数和已检查目录数，不编造完成百分比。应用重开后从任务与检查点恢复提示；已完成的任务显示在照片总数中。认证失效会停止任务并显示“需要重新登录”；暂时网络错误退避重试，连续任务尝试失败后可以手动重新加载，保留已完成目录。长任务在系统执行期限前让出，再继续下一段。

后台执行遵从 Android 调度及厂商省电策略，无法保证在系统强制停止后继续运行；下次打开会恢复调度。本次针对 Android 15 模拟器验收，真机及各厂商的后台策略仍需验证。
