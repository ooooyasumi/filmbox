# Android 0.3.1 验收记录

2026-11-12。主体实现提交 `a8e609b`；重新登录界面修正 `31f3bf0`；旧任务兼容与等待状态 `2ac788c`。版本代码 5，标签 `android/v0.3.1`。

- 20 项逻辑检查、16 项 Android 15 模拟器设备检查通过。
- 新增的隔离 WebDAV 场景验证：目录 403 保留旧照片索引并提供“打开网盘”，不要求登录；401 显示“重新登录”，之后的重复请求不再访问服务器；同账号成功连接后原资源库恢复。
- 单次 503 后自动恢复成功；429 后停止后续五次读取，显式恢复后重新可用。与本地图片、缓存、视频、选择、连续缩放及后台索引检查一同通过。
- 最后针对登录界面与云端查看器再检查 3 项，针对后台索引和恢复再检查 3 项，均通过。重新登录不再显示本地／云端切换或全部账号，直接定位原账号。
- 正式签名、R8 优化 APK 通过独立原生验收入口，验证启动、真实照片像素、查看器放大、卷轴和主题设置。交付文件与实际验收文件校验值一致。
- Go 引擎、发布 Lint、APK 签名／最低系统／架构／原生组件对齐／私密文件排除检查通过。Lint 无错误，保留 54 项建议。
- 与 0.3.0 签名一致，可以覆盖安装；最低 Android 11 / API 30，目标 API 35，arm64。后台任务等待网络时明确显示等待状态，只有进行中的任务显示进度动画。

检查只使用 Android 15 / API 35 arm64 模拟器、生成媒体和隔离 WebDAV 服务；未连接真实 Android 手机，也未访问个人资源库或真实百度／夸克账号。第三方服务维护、风控和权限仍需在其平台处理；没有将重新登录当作所有问题的通用解决方式。
