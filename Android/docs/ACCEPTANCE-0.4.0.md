# Android 0.4.0 验收记录

2026-11-13。主体实现 `8763594`；边缘归位及预览衔接修正 `ede54a0`。版本代码 6，标签 `android/v0.4.0`。本次只更新 Android，macOS 仍为 0.6.25。

- 24 项逻辑检查、20 项 Android 15 / API 35 arm64 模拟器检查通过。
- 34,595 条媒体记录的排布检查覆盖中间密度、原始比例、视口覆盖、无重复绘制、无重叠及双指中心定位；九个档位均可从头到尾访问全部照片。
- 设备端使用 5,000 条共享 8 张合成图片的记录检查连续双指缩放、松手吸附和年度总览；日期气泡在详细日期与年度密集视图中均可见。
- 延迟加载源验证同屏超过 500 个独立云端预览项全部完成，启动顺序从左上角按距离扩散，最多四个实际任务，上下各预取不超过 12 项，不触发原图下载。
- 快速划走会取消旧区域任务；任务尚未开始就被取消，也不会永久占住加载名额。高清预览替换前保留旧图，避免重新显示空白。
- 小资源库缩小后平滑靠齐顶部，设备端检查上方没有大块悬空；图片比例变化延后到滚动停止后合并处理。
- 查看器手势、横屏全屏、屏幕开孔避让、选择、筛选、卷轴、设置，以及本地／云端错误恢复检查一同通过。
- 正式签名、R8 优化 APK 通过独立原生验收入口，检查实际照片像素、查看器双击放大、卷轴和深色设置；像素采样避开新日期气泡。交付 APK 与实际验收文件的 SHA-256 一致。
- Go 引擎、发布 Lint、签名／最低系统／架构／原生组件对齐／私密文件排除检查通过。Lint 无错误，保留 55 项建议。
- 与 Android 0.3.1 的签名一致，可以覆盖安装；最低 Android 11 / API 30，目标 API 35，仅 arm64。

预览位图预算为堆上限的 1/20，限制在 8–24 MiB；这不是整个应用的内存上限。独立正式包验收在单张合成图片、查看器、卷轴与设置流程后记录总 PSS 59,898 KiB，不能据此推断大量真实媒体或视频使用时的峰值内存。

本次使用合成图片、独立延迟源和隔离 WebDAV 服务，未访问个人资源库或真实百度／夸克账号；未连接真实 Android 手机。不同手机的图形性能、编码支持与厂商后台策略仍需真机验证。
