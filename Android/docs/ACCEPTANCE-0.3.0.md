# Android 0.3.0 验收记录

发布日期：2026 年 11 月 12 日。主体实现提交：`e69d771`。版本代码为 4，发布标签为 `android/v0.3.0`。

- 20 项逻辑检查通过，包括九档密度、原比例排布、密集总览可见数量与取消后台排布计算。
- 14 项 Android 15 设备检查通过，覆盖索引、整理、缓存、视频、下载提示、照片流与查看器手势、设置导航，以及原有后台任务恢复行为。
- 照片流注入 5,000 条隔离媒体记录，复用 8 张程序生成照片，验证双指中间态不是固定档位、手指中心仍命中原照片、松手吸附、最小年度总览与返回较大档位。这是排布和交互检查，不代表 5,000 个独立原文件的读取性能测试。
- 本地文件进入原图下载入口会在网络操作前被拒绝，下载计数与活动文件集合保持不变。隔离 WebDAV 检查确认云端实际传输时显示底部下载提示，完成后移除，已下载预览继续优先使用。
- 查看器不再含图片缩放滑块；双击与双指缩放继续可用。启用模拟器顶部开孔，确认横竖屏工具栏在系统安全区域内，下载提示位于下半部、操作按钮上方。
- 设置已目视检查：独立页面、分组入口、外观子页、帮助、关于和许可的返回关系均通过。设置根页面无使用说明页脚。
- 实际经过 R8 优化的正式签名 APK 独立验收通过：启动、照片真实像素、查看器双击缩放、卷轴浏览、主题设置。交付包与实际验收包 SHA-256 相同。
- Go 引擎检查、发布 Lint 和 APK 检查通过。Lint 无错误，有 52 项建议，主要为依赖版本、现有 API 写法和品牌图标的单色变体建议。
- 签名与 0.2.0 一致，版本代码递增，支持覆盖升级。最低 Android 11 / API 30，目标 API 35，arm64；原生组件对齐检查通过。

测试环境为 Android 15 / API 35 arm64 模拟器，未连接真实 Android 手机，未使用个人照片、Mac 资源库或真实云盘账号。百度、夸克授权、厂商后台限制及真机手势帧率仍需实测。正式包单次基础浏览检查末尾总 PSS 为 59,947 KiB，不能视为大图库峰值或跨设备性能保证。

照片流连续缩放过程、年度密集总览、设置、视频、横竖屏和正式包截图均已保存并检查，记录位于本机 `.build/android-030-qa/`。参考手势视频不包含在测试资料或发行包内。
