# 使用与缓存机制

使用 SwiftUI 与 AppKit 构建的照片与视频浏览器，支持 **Apple 芯片 Mac、macOS 15 Sequoia 或更新版本**。以本地或云端文件夹为资源库，原文件留在原处。当前版本为 **0.6.26**。macOS 26 使用系统玻璃效果，macOS 15 使用兼容的材质样式。

## 云盘资源库

侧栏资源库旁的「＋」打开统一添加窗口，选择「云盘」可连接百度网盘、夸克网盘或 WebDAV。菲林盒内置从 OpenList 驱动提取的本地云盘组件，无需单独安装或部署 OpenList。登录后选择文件夹，可和本地文件夹一起在「所有项目」中浏览，也可以组合筛选两种来源，统一搜索、排序、收藏、隐藏与加入影集。

夸克使用添加窗口内的登录网页，完成后验证目录访问；百度使用 OpenList 在线授权服务并接收授权返回，也保留手动令牌入口。百度令牌刷新会经过 `api.oplist.org`，该方式依赖公共授权服务。WebDAV 支持 HTTPS 服务及本机 HTTP，OneDrive 等也可通过已有的 WebDAV 服务接入，本版没有 OneDrive 原生登录入口。

夸克会话在目录与媒体请求中更新并存回钥匙串，临时网络错误、单文件失败和钥匙串繁忙不会直接退出账号。0.6.5 起使用固定的专用凭据组件，后续更新主程序沿用同一登录存储；从旧版升级需重新登录一次，已有资源库及整理记录保留。

添加和重新登录页面按操作顺序说明登录、确认和选择目录的步骤。重新登录完成后直接恢复已有资源库，首次连接才需要选择资源库目录。

首次添加云端目录先完整建立索引，再一次展示文件数量和占位。失败保留旧索引，中断按完整目录检查点恢复；启动直接读取本地记录，自动云端校对间隔为 30 分钟。当前接口依靠列目录发现变化，差量合并索引，不保证服务端变化通知或完全免遍历。

缩略图默认只加载当前视口和附近约 16 项，可在设置的云盘页改为全库后台预加载。缺少封面时不自动下载完整照片；后台任务不为生成封面读取原视频流。双击照片、明确复制或「下载原文件」才准备原件，支持批量下载。底部任务入口显示实际网络活动、进度和流量；普通视频按需分段读取，没有持久分片缓存。云端 WebM 在连续浏览中要求明确下载后播放，独立查看器打开则显示原件下载状态。

预览缓存默认 2 GB，云端文件缓存默认 8 GB；原件在下载前检查可用缓存预算，当前查看／播放及导出中的文件受保护。设置支持按类别清理和重新建立索引，保留收藏、隐藏与影集。开启全库预载后，缓存不足会暂停；自动淘汰不会导致已预载文件循环下载。手动清理云缩略图会暂停后台并重置预载完成记录，用户继续时才重新预载。

全库后台预载只保存云端封面和读取比例，浏览时再解码。前台图片内存缓存预算为 64 MiB，后台预取不长期保留已解码图片；磁盘缓存仍供下次快速打开。元数据分小批更新，图库只调整受影响的照片和日期组，给鼠标、键盘及滚动留出响应时间。性能测量口径见 [性能记录](docs/PERFORMANCE.md)。

云端原文件在此版本只读，重命名和删除仅对本地文件启用。百度、夸克使用真实用户账号的端到端登录尚未验收；当前通过的是受控响应、授权回调、真实本机 WebDAV 以及媒体播放检查，不能据此保证各网盘当前账号、权限与会员限制下全部可用。实现与许可见 [CLOUD_ENGINE](docs/CLOUD_ENGINE.md)。

## 浏览与整理

资源库右键可设置仅用于菲林盒的名称，按住资源库行拖动可调整顺序，名称与顺序自动保存。首次读取时数量位置显示进度图标；点击所有项目会勾选全部资源库，再取消某个库可保留其余选择。常规设置默认忽略资源库内以点开头的文件及目录，只影响索引和显示，不删除磁盘文件。

添加或拖入文件夹，可组合选择资源库及子文件夹，也可查看所有项目。照片与视频保持原始比例，时间线随缩小从天合并到周、月；搜索、类型筛选及日期组内排序共用当前媒体顺序。

“筛选”可组合类型、文件格式、本地／云端来源和云端原图下载状态；格式支持多选。“已下载”只计算完整云端原文件，封面与缩略图不计入。状态从磁盘缓存恢复，完成下载、清理或淘汰后更新；在未下载条件下打开的照片会保持查看器，关闭后再从该筛选结果中移除。

平时单击照片或视频，选中一项并自动显示右侧文件信息；双击才打开查看器，也可用空格或回车打开。普通单选支持 ⌘C 复制文件。顶部「多选」进入多选模式，逐项点击可加入或取消选择；提供全选、一键复制及批量整理菜单。「复制」将所选原文件的 URL 写入系统剪贴板，可在访达等支持文件的应用中粘贴。点击「完成」或按 Esc 清空选择并返回浏览。查看器切换照片保留已有批量多选，普通单选则跟随当前媒体，重新启动默认关闭选择模式。

时间线中单击视频可就地预览，首次静音，可暂停或打开声音；本次会话后续预览沿用声音选择。切换文件、滚出可见范围、打开独立查看器或离开模式时结束预览。双击仍打开播放器。时间线和翻阅切换时跟随当前实际浏览位置，保留已有多选。

选择模式中按住鼠标拖过照片或视频，可沿途累加选择；支持从空白处起拖，回扫不会反选已有项目，靠近视口边缘会自动滚动继续选择。网格和照片卷均支持。时间线中按住 Option 拖动可拖出所选本地文件；包含云端文件的选择请使用「复制」，不会仅拖出其中的本地部分。

「翻阅」采用横向连续照片卷，可以滚轮前后浏览，再打开当前项目。照片和视频按视口自动适应：通常撑满可用高度，过宽时以宽度为限，完整显示并垂直居中。右下角滑块与 ⌘±／⌘滚轮仅缩放底部日期尺的刻度与天／周／月范围，不改变照片尺寸、顺序或当前浏览位置；日期尺与网格分别记住自己的尺度。底部日期尺与当前照片同步，支持滚轮、点击日期、拖动和键盘跳转，并保留多选。滑到当前视频便自动循环播放，首次默认静音；手动打开声音后，本次使用中的后续视频沿用声音选择。可手动暂停，应用退到后台、窗口隐藏或离开翻阅时停播。

照片卷只为当前聚焦的照片获取完整原图并生成最长边4096像素高清显示，已有原件缓存直接使用。划走即取消没有其他消费者的未完成下载；完成的原件保留在缓存中，返回时复用。邻近照片按距离顺序只预载左右各4张缩略图，不自动下载原件。应用退到后台、窗口隐藏、离开照片卷或进入多选时结束聚焦高清请求；手动下载及其它查看器仍需要的共享请求会继续。当前图保留小图和下载进度，高清就绪后平滑替换。“未下载”条件不会在当前图完成时自动跳走，离开这张后才更新结果。

两种日期尺使用紧凑的日期比例：每个有照片的月份保留有限长度，再按照片数量为日期适度加长，密集拍摄不会挤走其它月份。空日期不占等长空间；同一日期内部浏览时，刻度也连续移动，点击或拖动可准确跳转。主刻度与日期文字一一对应，其余真实日期仅显示间距足够的淡色短刻度，不叠加装饰线。列表缩略图大小与换行不再拉长日期尺；照片卷底部仍可独立调整日期尺尺度。当前日期保持可读，年份始终跟随对应日期显示。

照片查看器底部提供缩放滑块、减／加按钮、当前比例及适应窗口，并支持快捷键缩放、鼠标位置缩放、触控板捏合、双击放大与还原、拖动平移、适应窗口及实际大小。照片与视频均支持系统全屏，Esc 优先退出全屏，再次按下返回图库。独立查看器中的视频仍使用系统播放控件。

打开照片时保留已有小图，本地读取和已缓存原图解码安静完成；当前云文件实际传输时显示“正在下载”及进度，排队、暂停沿用真实任务状态。失败按已确认的原因显示，并提供重新登录、连接文件夹、检查网络或刷新等对应操作；未知原因提供脱敏诊断信息，不把读取或解码失败推断成网络问题。可恢复的请求先自动处理，不反复要求无效重试。底部下载入口位于左下角项目数量旁，只显示正在下载的数量，不显示速度。

WebM（VP9／Opus）可直接播放、跳转和循环，无需转换完整视频。系统无法取帧的格式优先复用同名导出封面，无封面时由内置 FFmpeg 抽帧；补齐时长、尺寸和编码，并沿用磁盘缩略图缓存。WebM 查看器使用标准视频控件，照片卷仍保持首播静音和会话声音选择。

隐藏会从所有项目、收藏、文件夹和影集中同时排除媒体，可在「隐藏」中恢复；原收藏与影集关系保留。影集可自由创建、重命名和删除，同一媒体可加入多个影集，成员管理不复制或删除原件。

单文件重命名保留扩展名，并同步索引、收藏、隐藏、影集与当前查看位置。删除文件采用系统废纸篓并要求确认；部分失败时保留失败项目。影集中的普通 Delete 只移除成员，⌘Delete 移动原文件。

照片与视频选择仅保留右上角圆形勾选，时间线和照片卷均保持画面原色，不叠加选择遮罩或改变明暗。界面控件与键盘焦点采用无描边的浅色高亮。侧栏、筛选、工具按钮、照片卷和查看器缩略导航不再附加底部横线；照片卷悬停不显示细边框，日期尺继续提供时间定位。深色与浅色均保留可辨认的键盘焦点。

## 构建与数据

开发构建使用 Swift 6.2、macOS 26 SDK 及 Go 1.23 或更新版本；生成的应用运行要求为 macOS 15 或更新版本。当前构建目标为 Apple Silicon；用户无需安装命令行工具。开发打包会从固定校验的 FFmpeg 官方源码构建独立 helper，首次需要联网下载源码，详见 [CODEC_RUNTIME](docs/CODEC_RUNTIME.md)。

```sh
swift run FilmboxCoreChecks
./scripts/check-behavior.sh
./scripts/check-media.sh
./scripts/check-interaction.sh
./scripts/check-grid-selection.sh
./scripts/check-double-click.sh
./scripts/check-timeline.sh
./scripts/check-playback.sh
./scripts/check-formats.sh
./scripts/check-web-playback.sh
./scripts/check-cloud.sh
./scripts/check-resource-recovery.sh
./scripts/build-app.sh
```

检查范围、窗口复验与实际通过数量见 [ACCEPTANCE](docs/ACCEPTANCE.md)，打包步骤见 [BUILD](docs/BUILD.md)。

- 资源库、安全书签、收藏、隐藏、影集及离线索引：`~/Library/Application Support/com.filmbox.app/catalog.json`。旧记录兼容，损坏记录保留并报错。
- 缩略图：`~/Library/Caches/com.filmbox.app/thumbs/`，默认上限 2 GB。沿用已有缓存，重启先显示索引，再检查变化；离线保留索引及已缓存预览。
- 云盘登录凭据保存在 macOS 钥匙串，不进入 catalog；已缓存云端原片位于 `~/Library/Caches/com.filmbox.app/cloud-assets/`，可在设置清理。
- 添加文件夹不复制原件，移除资源库不删除原文件。本地重命名和移到废纸篓会明确修改原件。云盘通过网络读取，不上传媒体；云盘辅助进程仅监听随机端口的 127.0.0.1，并要求会话令牌认证。WebM 播放通过独立只读流读取当前缓存文件，退出播放会撤销访问。
- 0.3.0 文件管理窗口验收使用独立复制的合成夹具，未重命名或删除用户原片。

媒体兼容取决于系统与内置解码器；视频播放走原生播放器或 WebM 直接播放路径，并非所有容器和编码均可播放。图片查看预览最长边为 4096 像素。尚未完成十万级图库或 Intel 实机测试。本地构建使用稳定的本地证书签名并启用 Hardened Runtime，对外分发仍需 Developer ID 签名、公证及凭据组件迁移规划。

版本见 [CHANGELOG](CHANGELOG.md)，设计见 [ROADMAP](docs/ROADMAP.md) 与 [品牌规范](design/lighttable-v1.1/README.md)，参考归属见 [THIRD_PARTY_NOTICES](THIRD_PARTY_NOTICES.md)。
