# 下载与安装

## 版本与校验

macOS 0.6.26 适用于 Apple Silicon / arm64、macOS 15 或更新版本。Android 0.4.1 适用于 Android 11 / API 30 或更新版本、arm64 设备。公开下载地址以 README 中的正式仓库 Releases 为准，地址待负责人提供。

每个平台的发布文件应同时提供更新说明、`SHA256SUMS`、对应源码提交及文件树 SHA-256。macOS 产物为 `Filmbox-0.6.26.zip`，Android 为 `Filmbox-Android-0.4.1-arm64.apk`。历史发布保存在各自版本目录。

在 Mac 或 Linux 终端校验单个文件可运行以下命令，将输出与该次发布的 SHA-256 比较。

```sh
shasum -a 256 Filmbox-0.6.26.zip
shasum -a 256 Filmbox-Android-0.4.1-arm64.apk
# 发布目录附有清单时
shasum -a 256 -c SHA256SUMS
```

Windows PowerShell 可使用 `Get-FileHash 文件名 -Algorithm SHA256`。校验值不一致时删除下载的副本并重新下载。中断后的文件可能不完整，浏览器能否续传取决于下载服务器。发布脚本核对最终文件，验证脚本会拒绝损坏或混用版本的产物。

## macOS

1. 下载对应 ZIP，校验并解压，将 `Filmbox.app` 拖到“应用程序”。
2. 从“应用程序”打开菲林盒，按系统要求允许访问所选文件夹和外置磁盘。
3. 点击资源库加号，选择包含照片或视频的文件夹。外置磁盘需保持挂载。

公开下载前需要 Developer ID 签名、Apple 公证和票据附加。当前缺少正式分发身份，本地开发证书生成的候选包会受到 Gatekeeper 限制。网站须标为测试候选包，发布者完成正式分发验收后再更新状态。安装帮助不要求用户全局关闭 Gatekeeper。

普通同签名升级时先退出应用，再替换应用程序，资源库及缓存沿用原本机位置。切换到 Developer ID 的版本采用独立凭据服务，云盘需要重新登录，既有目录索引和整理记录保留。详细迁移依据见 `DISTRIBUTION.md`。

卸载通常只删除应用本体。清理本机资料前先移除云盘账号、清理缓存并备份整理记录。完整本机路径见根 `PRIVACY.md`。

## Android

1. 在支持的 arm64 设备下载 APK，核对 SHA-256。
2. 从系统文件管理器打开 APK。如系统要求，为当前使用的浏览器或文件管理器开启“允许安装未知应用”。安装完成后可恢复该权限。
3. 打开菲林盒，授权允许访问的相册项目，或使用系统文件选择器添加文件夹。连接云盘前阅读登录页中的第三方授权说明。

更新时安装同一应用标识、相同签名且版本代码更高的 APK。正式包沿用原发布签名。自行构建的 debug APK 或其他签名无法覆盖正式版，Android 会明确拒绝安装。系统提示“更新不兼容”时，请核对来源和签名，先保留现有安装及整理记录。卸载会删除应用私有数据库和设置。

原图与预览是应用缓存，可能被预算回收、手动清理或系统回收。需要长期保留的云端文件可通过系统分享另存到其他位置。

百度、夸克仍需专用真实账号端到端验收，当前按实验接入提供。NAS 需要配置 WebDAV，Android 要求 HTTPS。遇到问题请提供平台、版本、来源、复现步骤及脱敏截图。修复与恢复规则见 `RECOVERY.md`，真实账号验收范围见 `CLOUD-ACCEPTANCE.md`。
