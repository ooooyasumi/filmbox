# 网站与宣传片能力核对

本轮截至 2026-11-24，核对 macOS 0.6.26、Android 0.4.1 的源码与自动检查，以及网站 v005 和三支最终版短片。短片逐段画面抽检，并对照旁白／字幕生成记录，未完成最终成片全部音轨的逐句验收。视频的二进制保持原文件校验值，素材保存在独立宣传目录。

| 宣传内容 | macOS | Android | 调整与测试状态 |
| --- | --- | --- | --- |
| 本地文件夹 | 系统文件选择器，原路径索引 | SAF 文件夹与系统相册权限 | 可保留宣传 |
| 移动硬盘、SD 卡 | 系统挂载、文件夹授权后读取 | 取决于设备连接、文件系统、系统挂载与 SAF | 安装帮助注明条件，避免承诺任意设备直连 |
| 百度、夸克 | 已有登录和只读驱动 | 已有 WebView 登录与同一驱动 | 实验接入，专用真实账号四组流程仍未验收 |
| NAS | WebDAV 服务器接入 | HTTPS WebDAV 接入 | 明确写 WebDAV，不能表述为原生 SMB／NFS 挂载 |
| 本地与云端统一浏览 | 支持多库与全部项目 | 支持多库与全部项目 | 隔离 WebDAV 可验证流程，真实提供商状态另列 |
| 原比例照片 | 原构图适应布局与视口 | 原构图适应布局与视口 | 预览质量、极端比例和解码支持受平台限制 |
| 横向胶片与日期尺 | 照片卷与底部尺，网格右侧尺 | 照片卷与底部尺，网格为悬浮日期 | 短片的桌面日期尺画面不能代表手机网格界面 |
| 调整网格密度 | 滑块、快捷键和触控板 | 双指连续缩放并吸附 | 影片中的滑块按桌面交互展示，手机说明使用手势 |
| 翻到视频播放 | 自动播放设置启用时聚焦播放 | 同样由设置和浏览状态控制 | 默认静音，需手动打开声音 |
| 账号、收藏、影集跨端同步 | 本机保存 | 本机保存 | 当前未实现同步，网站不应暗示自动同步 |

## 三支短片

1. 《等一下我找找》约 32.6 秒。6 秒附近展示电脑、硬盘和网盘，12 秒附近展示无人机、手机、相机和运动相机图示。表达应指读取这些设备产出的文件，不能解释为直接控制相机或自动导入任意设备。18 秒附近的日期尺为桌面交互演示。
2. 《这一格装不下》约 32.4 秒。原比例构图与密度调整有客户端实现。约 18 秒的滑块为桌面操作，Android 对应双指手势。视频画面为产品演示，具体控件外观以客户端为准。
3. 《一起回看》约 40.3 秒。12 秒附近展示多文件夹、18 秒附近展示胶片，24 秒附近展示视频。自动播放需对应设置启用，默认静音。海浪声音属于该宣传片的音画呈现，后续重剪建议加入点按音量的动作，避免让观众理解为默认有声。

网站新版本在下载／帮助区说明实验云盘状态、WebDAV 条件、移动端差异与默认静音，播放器补充桌面演示说明。原视频可继续作为演示资料，正式对外发布前应确认上述接入条件已对观众可见。
