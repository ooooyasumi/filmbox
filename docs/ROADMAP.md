# 菲林盒 · Filmbox 版本规划

当前版本：**0.6.1**，已完成本轮实现与本机验收。

| 版本 | 主要范围 |
| --- | --- |
| 0.1.0–0.2.0 | 本地文件夹资源库、原比例时间线、筛选排序、收藏、元数据、设置与关于 |
| 0.3.0–0.3.13 | 隐藏与影集、文件管理、连续翻阅、查看器缩放、多选与拖选、格式兼容 |
| 0.4.0–0.4.3 | 浏览位置互相跟随、视频就地预览、紧凑连续日期尺及稀疏刻度 |
| 0.5.0 | 内置云盘连接、本地与云端混合浏览、媒体缓存、登录与账号管理 |
| 0.6.0 | 完整索引原子发布、可恢复校对、受控缩略图预载、下载状态与流量、稳定比例更新、分类清理及统一添加入口 |
| 0.6.1 | 账号登录失效集中提示、同账号停止加载、缓存保留与明确重连恢复 |

## 0.6.0 已确认范围

1. 首次完整索引后正式展示；后续差量合并记录，保留未变媒体的元数据与用户整理。
2. 云盘不保证首轮返回宽高；未知云媒体方形占位，可靠比例后补，局部过渡并保留当前位置。
3. 默认仅加载视口与附近缩略图，可主动开启全库后台预载；没有封面不偷偷取原图。
4. 独立查看与明确下载可获取原件；下载状态、真实流量和后台任务可见。
5. 分级清理缓存，索引采用重建而非清空用户资料；使用中的原件保留。
6. 添加资源库统一模态，包含本地选择／拖入与云盘登录／选目录。

不纳入本轮：每个资源库单独覆盖下载设置、新增另存导出工作流，以及四个独立对外测试版本。

## 实现与验收边界

- 保留兼容现有 catalog，不在本轮迁移 SQLite。云目录 staging 和完成日志单独持久化，重建不先删旧索引。
- 现有提供方以目录列表为主，自动校对降频，不能保证以后只请求变化文件；手动刷新仍完整核对。
- 十万记录、千目录的合成压力测试只衡量本地索引处理，不代表真实云盘接口速度。
- 自动测试使用临时目录、随机测试账号和本机合成服务；正式升级前备份当前用户记录。
- 更新内容见 [CHANGELOG](../CHANGELOG.md)，最终测试、窗口和打包结果见 [ACCEPTANCE](ACCEPTANCE.md)。

品牌沿用四块标志，中上块为蓝色，其余随背景使用纯黑／纯白，不使用大面积蓝底。
