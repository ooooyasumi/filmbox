# 连接问题与恢复

适用于 macOS 0.6.25 / Android 0.3.1。问题按底层证据分类，不通过搜索错误文案或媒体类型猜测。云盘组件错误不会写出签名链接、Cookie、令牌、上游响应正文；诊断复制只包含应用版本、固定错误代码和来源类别。

| 已确认的情况 | 用户看到的内容 | 处理方式 |
| --- | --- | --- |
| 账号接口明确拒绝登录、保存的凭据不可用 | 需要重新登录 | 打开该账号登录入口，保留资源库和旧索引 |
| 上游网络连接失败 | 网络未连接 | 网络设置；连接恢复后检查受影响的资源库 |
| 请求超时 | 连接超时 | 网络设置或稍后刷新，不声称账号失效 |
| 云盘服务异常 | 云盘暂时不可用 | 自动尝试后停止，打开网盘确认状态 |
| 请求频率限制 | 云盘请求受限 | 停止连续请求，稍后刷新 |
| 403 等权限拒绝 | 云盘拒绝访问 | 在网盘中检查权限或账号限制，不断言重新登录可解决 |
| 原文件大小与索引不一致 | 原文件未完整读取 | 刷新该资源库，核对原件后重新打开 |
| 文件或目录不存在 | 找不到文件或文件夹 | 刷新该资源库，核对移动或删除 |
| 本地设备或目录不可访问 | 资源库未连接／需要访问权限 | 连接设备或重新选择原目录授权 |
| TLS 证书验证失败 | 无法验证云盘连接 | 检查服务器证书、地址、设备时间，保持证书验证开启 |
| 无法解码媒体 | 无法预览此文件 | 用其他应用打开，确认格式支持或文件损坏 |
| 原因尚不明确、连接组件不可恢复 | 未能完成加载／云盘连接组件不可用 | 明确下一步并可复制脱敏诊断，不重复给出无条件“重试” |

目录与链接读取在可恢复错误时自动再尝试一次，间隔约 600 毫秒。账号失效、拒绝访问、文件不存在、证书问题和限流不会进行这种即时重试。连接组件断开时可重建本机连接；显式登录操作不重放。

同一账号持续网络、服务或组件错误后抑制连续请求约 15 秒；限流约 60 秒，登录失效则等用户完成登录。已有原图和预览缓存优先读取，不受新网络请求的抑制影响。手动刷新释放对应账号的临时抑制；原有索引在完整核对成功前保留。Android 的后台索引针对可恢复失败最多退避重试两次，等待期间保留具体原因；最终失败提供处理入口。macOS 在恢复网络或回到应用时检查受影响的资源库，Android 在可用网络恢复时继续相应任务。系统后台限制仍然适用。

媒体下载链接被 401／403 拒绝时，先更新链接一次；再次拒绝后通过云盘目录接口核验账号。CDN 的单个拒绝不能证明账号已退登。百度刷新接口临时异常或不完整响应不作为凭据过期；WebDAV 的 403 和目录内的权限错误也不作为空目录或退登提交。

提示采用中性外观，错误就近出现在资源库、查看器或任务中；相同索引错误不再额外汇总成一条黄色警告。“继续”仅用于真正暂停的任务。移除资源库同时移除其错误状态，成功检查后清除对应连接问题。

自动检查使用隔离 WebDAV 服务、临时索引与合成媒体。没有访问个人资源库或真实百度、夸克账号；实际平台风险控制和服务维护仍可能需要用户在网盘中处理。
