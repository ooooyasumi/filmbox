# 媒体读取与加载反馈

0.6.25，2026-11-12。

## 文案与判断

云端失败保留结构化原因，目录索引、下载、查看器、任务与云盘设置共用恢复方式。登录失效才显示重新登录；网络与超时、服务异常、限流、权限、文件不存在和证书错误各自提供处理入口。未知原因明确说明尚不能确认，并提供不含凭据的诊断信息。完整规则见 [RECOVERY.md](RECOVERY.md)。

本地 WebM 的本机 HTTP 服务不属于云端来源。本地解码失败不会推断为网络故障；无法预览时可通过其他应用确认文件或格式。资源库未连接时提供连接原文件夹的操作，缓存空间不足保留实际容量和处理建议。

缩略图占位在读取中只表达加载，不提前显示失败。本地媒体不显示云端状态徽标；云盘没有封面仍为“暂无预览”。原生视频失败后解除 AVPlayerView 的失败播放器及系统控件，由菲林盒提供原因与处理入口，避免叠加系统的网络推断；正常文件安装时恢复控件。

## 提示规则

| 场景 | 列表 | 照片卷／独立查看器 |
| --- | --- | --- |
| 本地照片正常读取 | 安静占位，不旋转加载图标 | 保留可用小图，读取清晰图时不弹浮层 |
| 云端缩略图未就绪 | 小型加载状态及云端标记 | 非焦点同左；焦点原图另外跟踪 |
| 云端原图正在下载／排队 | 以云端状态标记表达 | 保留小图；超过220毫秒显示实际下载／排队状态和可用进度 |
| 云端原图已完整缓存，正在本机解码 | 直接复用高清派生预览 | 不弹加载浮层，完成后替换清晰图 |
| 照片下载被暂停 | 静态状态 | 静态暂停图标，不持续转圈 |
| 本地或完整缓存视频短暂缓冲 | 600毫秒内不显示中央加载提示 | 同左，超过后提示正在加载 |
| 云端视频下载／流播缓冲 | 超过220毫秒显示正在下载 | 同左；就绪后自动移除，保留手动暂停意图 |
| 文件损坏、磁盘离线或登录失效 | 静态失败／连接状态 | 立即给出原因及对应处理入口 |

照片的读取状态与界面反馈分开：后台仍跟踪解码是否完成，但本地读取不再被用作显示加载浮层的理由。下载完成后不会把本机解码继续显示为网络下载。中央提示设短暂门槛，不延迟实际任务；切走后其展示任务随视图取消。底部下载指示仍由真实云端传输状态驱动。

## 低清封面

仅对云盘提供、实际最长边小于1024像素的封面进行高斯模糊，模糊半径约为小图最长边的2.5%。处理在后台按封面自身像素尺寸完成，不扩大位图，不改变布局比例，也不在整个滚动画布上持续运行滤镜。沿用共享缩略图内存预算。

原件派生预览、经过验证的高清缓存、本地图片以及较清晰的网盘封面不进行模糊；原图就绪后的高清替换仍复用已有流程。磁盘封面保持原始缓存内容，展示用的小图在后台处理并放入有上限的内存缓存。

## 刷新范围

- 左下角刷新检查全部资源库；每个资源库右键的“重新加载”仅检查该库。相同范围的重复请求合并，进行中的云端任务不取消重开；本地扩大检查范围时合并尚未完成的目录。
- 本地手动刷新／重连核对文件头并更新预览验证代际，不预解码全部原图；常规后台核验继续复用相同文件修订的元数据。云端仍可能检查每级目录清单，但不下载媒体本体。
- 本地修订同时包含设备、文件身份、变更时间、创建／修改时间和大小；显式验证还更换缓存代际，不以同名、同大小、同修改时间判定预览永远有效。
- 目录被其他电脑替换后，已选择且仍可访问的路径优先，失效书签可更新；未挂载时不主动尝试挂载。离线保留旧索引，在线且成功检查的空目录才能清空媒体。
- 既有云端目录无变化时复用检查点，媒体差异为空时不重排；资料库去重仍核对磁盘文件身份，外部删除或改变资料库文件不会被误当成已保存。

- 新增、重新连接本地目录或挂载磁盘：检查相关本地资源库，不触发云盘遍历。
- 新增云端目录：仅索引新资源库，既有同账号目录不跟着重跑。
- 本地文件管理：只暂停可能发布旧本地路径的本地扫描，正在进行的云端索引继续；结束时按需恢复待校对的本地根目录。
- 主动完整刷新、重新建立全部索引、定期云端校对、账号恢复：保留相应刷新；目前的提供商没有统一可靠的变更推送，定期校对仍可能检查目录。

## 保存旋转

查看器左旋／右旋以90度为单位，将方向写进本地 JPEG、PNG、TIFF、HEIC／HEIF 原文件。使用 ImageIO 的无损复制并更新文件方向，不重新压缩 JPEG 像素；这是文件修改，重启或重新扫描仍有效。随后更新尺寸与文件修订，已有预览自然失效，收藏、隐藏、影集和项目身份不变。

写入在独立文件操作 actor 中执行。先核对原件修订、拒绝符号链接与多帧文件，再写临时文件、校验方向及尺寸、复制 Finder 标签／ACL／创建日期等文件属性，最后协调替换。校验失败不覆盖原件。云盘接入当前为只读；RAW 和不能安全保存的格式保持原件，不偷偷转格式。

依据：[Apple 文件方向选项](https://developer.apple.com/documentation/imageio/kcgimagedestinationorientation)、[ImageIO 文件写入](https://developer.apple.com/documentation/imageio/cgimagedestination)。
